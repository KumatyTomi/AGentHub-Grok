  AGentHub-Grok 0.2 — instalator lokalnego klastra (Windows 10/11)
  ALPHA Codex · BETA mesh-core :8765 + UI · GAMMA Ollama
  LOCAL ONLY — bez chmury jako default

1. Rozpakuj ZIP. PowerShell / INSTALUJ.bat jako Administrator.
2. Edytuj config\cluster.env (powstaje z example).
3. Kolejność: GAMMA → BETA → ALPHA → TEST-SIECI.
4. BETA po instalacji:
     E:\AgentMesh\beta\start-core.cmd
     Przeglądarka: http://127.0.0.1:8765/
5. ALPHA: E:\AgentMesh\alpha\start-codex.cmd  (codex --oss → Ollama)
6. GAMMA: E:\AgentMesh\gamma\start-ollama.cmd
